Welcome to Karada! This tutorial walks you through transforming any standard REST API into a production-ready Model Context Protocol (MCP) server that AI agents can use immediately.

**What you will accomplish**:
1. Create a project in your team workspace
2. Ingest an OpenAPI or Swagger specification with Auto-MCP
3. Review auto-generated MCP tools and parameters
4. Deploy the server to Karada Cloud or run locally

---

## Prerequisites

Before beginning, make sure you have:
- A [Karada.ai](https://karada.ai) account.
- A valid OpenAPI (v3) or Swagger (v2) URL (e.g., `https://api.example.com/openapi.json`) or file. If you need a sample, test with the public [Petstore Swagger Spec](https://petstore.swagger.io/v2/swagger.json).
- An MCP client (such as Claude Desktop or Cursor).

---

## Step 1: Create a Workspace & Project

A project serves as the container for your MCP server deployments, plugins, and usage tracking.

1. Log into your **Dashboard**.
2. Select or create your **Team Workspace**.
3. Click **Create Project** in the upper right.
4. Select the **Auto-MCP** template.
5. Enter a project name (e.g., `Petstore AI Tools`).

---

## Step 2: Configure Auto-MCP

Karada's Auto-MCP engine parses your API definition into native tool schemas.

<Steps>
  <Step title='Select Specification Standard'>
    Choose between **OpenAPI v3** or **Swagger v2** based on your API schema format.
  </Step>
  <Step title='Provide Specification URL or Upload'>
    Paste the publicly accessible URL to your `openapi.json` / `swagger.yaml`, or upload the file directly from your disk.
  </Step>
  <Step title='Review Detected Tools'>
    Karada parses the routes into discrete MCP tools. Verify the detected tool names, parameter schemas, and descriptions. These define how LLMs will decide when and how to call your API.
  </Step>
</Steps>

---

## Step 3: Generate & Deploy

With tools confirmed:

1. Click **Generate Server**.
2. Karada's Go engine generates the complete MCP server structure.
3. Select your deployment target:
   - **Deploy to Karada**: Instantly provision an isolated, managed container with a secure HTTPS/SSE endpoint.
   - **Download as ZIP**: Run and inspect the server on your local machine or private VPC.

### Running Locally (Downloaded Server)

If you download the standalone build to execute on your machine:

```bash
# Unzip the downloaded bundle
unzip karada-mcp-server.zip
cd karada-mcp-server

# Install dependencies and build
npm install
npm run build

# Start the generated MCP server
npm start
```
