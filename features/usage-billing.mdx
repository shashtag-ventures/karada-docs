Karada provides transparent, real-time observability into your infrastructure consumption. The **Usage** tab in your Project Dashboard delivers a comprehensive view of how your deployments, Auto-MCP servers, and plugins perform in production.

---

## Real-Time Telemetry

Karada tracks core operational metrics over a rolling **30-day window**:

<CardGroup cols={3}>
  <Card title='Tool Invocations' icon='signal'>
    Total tool executions and API calls routed through your MCP servers and Gateway proxies.
  </Card>
  <Card title='Bandwidth Consumption' icon='cloud-arrow-down'>
    Total egress and ingress volume across AI agent requests and backend API responses.
  </Card>
  <Card title='Error Rate' icon='circle-exclamation'>
    Percentage of requests returning client or server errors (4xx / 5xx). Healthy servers maintain under 1%.
  </Card>
</CardGroup>

## Managing Subscriptions

To view consumption against quota limits or update payment credentials:

1. Open **Account Settings** → **Billing**.
2. Review active usage against monthly plan allocations.
3. Select **Upgrade** or **Manage Subscription** to adjust plans via our secure payment portal.
