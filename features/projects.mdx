In Karada, a **Project** is the fundamental container for your deployed services, Auto-MCP servers, plugins, and resource limits.

Every Project resides within a **Workspace** (Team), ensuring billing, role-based access control, and usage telemetry remain centrally organized.

---

## Creating Projects

When creating a new project with Karada Auto-MCP, Karada manages the underlying containerization and deployment lifecycle for you. You provide your API specification (OpenAPI v3 or Swagger v2 via URL or upload), and Karada handles parsing, schema translation, tool extraction, and runtime provisioning automatically.

---

## The Project Dashboard

The Project Dashboard provides operational control and visibility over your MCP servers:

### Usage Telemetry

If your project powers AI coding agents or processes automated tool calls, the **Usage** tab provides real-time telemetry:

- **Total API & Tool Invocations**: Track query frequency across agents
- **Bandwidth Transfer**: Monitor data payload volume
- **Latency & Error Rates**: Detect upstream API timeouts or schema mismatches

### Configuration & Secrets

The **Settings** tab controls environment variables, domains, and access policies:

- **General**: Customize project title, description, and vanity domains.
- **Environment Variables**: Store sensitive API keys, database credentials, and Bearer tokens. Karada encrypts all secrets at rest using AES-256-GCM and injects them securely at runtime.
- **Plugins**: Enable or reconfigure installed extensions (analytics, rate limiting, security headers).
- **Danger Zone**: Transfer project ownership or permanently decommission deployments.
