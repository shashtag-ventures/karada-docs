The **Karada Registry** is a curated catalog of production-ready Model Context Protocol (MCP) servers. Browse verified servers for popular SaaS APIs, connect them directly to your Karada Gateway with one click, or publish your own for team and community discovery.

---

## Browsing the Registry

The Registry lists MCP servers complete with verified metadata:

- **Server Title & Description**: Functional overview and provider details
- **Tool Catalog**: Full list of callable tools with JSON input parameter schemas
- **Quickstart Configs**: Copy-ready configurations for Claude Desktop, Cursor, and Streamable HTTP clients
- **Required Secrets**: Environment variables and authentication headers needed at runtime
- **Repository Links**: Source code and deployment manifests

Use the search and category filters to locate pre-built servers for databases, analytics platforms, CRMs, and developer tools.

---

## Connecting a Registry Server to Your Gateway

From any Registry detail view, click **Connect to Gateway** to multiplex the server into your active MCP Gateway:

1. Karada creates an isolated namespaced connection using the server's canonical prefix (e.g., `github__`, `stripe__`).
2. Configures the upstream Streamable HTTP endpoint automatically.
3. Prompts for required API keys or secrets, storing them in your encrypted vault.

All tools from the newly connected server appear in your Gateway's unified tool catalog immediately.

---

## Publishing to the Registry

Any MCP server built on Karada—via Auto-MCP or custom code—can be published to the Registry:

1. Open your **Project Dashboard**.
2. Select **Publish to Registry** from the project menu.
3. Karada runs automated compliance checks to ensure your server responds to protocol handshakes (`initialize` and `tools/list`).
4. Upon passing validation, your server is indexed with live documentation and parameter schemas.

### Claim Precedence & Verification

For high-volume public APIs (such as Stripe, GitHub, and Jira), Karada enforces **claim precedence**. The initial verified publisher holds the canonical listing. Additional contributors can submit claim requests or publish specialized variants under dedicated namespaces.

## Registry Plugins

The Registry also indexes **Plugins**—modular extensions that inject telemetry, caching, or security logic into any MCP server:

- Discover approved plugins for your organization
- Package custom handlers and deploy them across team workspaces
- Hook into the MCP request lifecycle without altering upstream server code
