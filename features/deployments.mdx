Karada eliminates the operational friction of deploying and hosting Model Context Protocol (MCP) servers. Whenever you compile an Auto-MCP project or connect an API specification, Karada provisions an isolated, high-performance Go container runtime ready to handle concurrent tool invocations from AI assistants and autonomous agent fleets.

---

## High-Throughput Architecture

Karada runtimes are engineered for production agent workloads:

- **Stateless Streamable HTTP Transport**: Modern MCP protocol standard (`POST /mcp` + `stdio`, protocol `2026-07-28`), eliminating legacy stateful connection overhead.
- **Sub-5ms Execution Latency**: Compiled Go engine with zero reflection overhead.
- **10,000+ Concurrent Streams**: Handles bursty multi-agent workloads with ease.
- **Automated TLS & Custom Domains**: Free automated Let's Encrypt certificates or custom domain bindings (e.g., `mcp.yourcompany.com`).

## How Deployments Work

A deployment represents a specific build artifact and isolated runtime state for your MCP server.

```mermaid
sequenceDiagram
    participant User as Developer / CI/CD
    participant Karada as Karada Engine
    participant Runtime as Stateless Streamable HTTP Container
    participant AIClient as AI Harness (Cursor / Claude Code / Windsurf)

    User->>Karada: Ingest API Spec & Generate
    Karada->>Runtime: Compile Go Engine & Attach Plugins
    Runtime-->>Karada: Provision High-Throughput Endpoint
    Karada-->>User: Secure HTTPS Endpoint Generated
    User->>AIClient: Connect Endpoint or Gateway URL
    AIClient<-->>Runtime: AI invokes tools via Streamable HTTP (sub-5ms)
```

### Automated Build & CI/CD Pipeline

When you click **Deploy** or trigger a repository webhook:

1. **Spec Ingestion & Validation**: Validates your API specification (OpenAPI or Postman).
2. **Go Compilation**: Builds the native Go binary with compiled schemas and active composable plugins.
3. **Endpoint Provisioning**: Exposes a secure HTTPS Streamable HTTP endpoint with sub-5ms response latency.

## Managing Deployments & Health

From the **Deployments** tab in your Project Dashboard, manage your runtime lifecycle:

### Real-Time Build & Runtime Logs

Every build stream is captured live. If an upstream specification contains unresolved `$ref` pointers or missing credentials, the build log highlights the exact error for rapid troubleshooting.

### Zero-Downtime Rollbacks

If a spec change or configuration tweak causes issues, revert instantly. Click the action menu next to any previous successful deployment and select **Rollback**. Karada routes traffic back to the prior stable container with zero downtime.

### Custom Domains & Managed TLS

By default, every project receives a secure `https://<project-slug>.karada.ai` endpoint. You can also bind custom enterprise domains via standard DNS CNAME records. Karada automatically issues and renews TLS certificates.
