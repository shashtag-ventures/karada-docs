Karada eliminates the operational friction of deploying and hosting Model Context Protocol (MCP) servers. Whenever you generate an Auto-MCP project or connect an API specification, Karada provisions an isolated, automated cloud runtime ready to handle tool invocations from AI assistants.

---

## How Deployments Work

A deployment represents a specific build artifact and isolated runtime state for your MCP server.

```mermaid
sequenceDiagram
    participant User as Developer
    participant Karada as Karada Engine
    participant Runtime as Secure Container
    participant AIClient as AI Client (Cursor / Claude)

    User->>Karada: Ingest OpenAPI Spec & Generate
    Karada->>Runtime: Compile, Build & Containerize
    Runtime-->>Karada: Provision Secure Endpoint
    Karada-->>User: Secure HTTPS/SSE URL Generated
    User->>AIClient: Connect Single URL
    AIClient<-->>Runtime: AI invokes tools via MCP
```

### Automated Build Pipeline

When you click **Deploy** in your dashboard, Karada orchestrates the full compilation and provisioning sequence:

1. **Spec Ingestion**: Validates your OpenAPI v3 or Swagger v2 schema.
2. **Container Assembly**: Builds the server with all dependencies and active plugins.
3. **Endpoint Provisioning**: Exposes an HTTPS endpoint supporting both Server-Sent Events (SSE) and Streamable HTTP transports.

## Managing Deployments & Health

From the **Deployments** tab in your Project Dashboard, manage your runtime lifecycle:

### Real-Time Build & Runtime Logs

Every build stream is captured live. If an upstream specification contains unresolved `$ref` pointers or missing environment variables, the build log highlights the exact error line for rapid troubleshooting.

### Zero-Downtime Rollbacks

If a spec change or configuration tweak causes issues, revert instantly. Click the action menu next to any previous successful deployment and select **Rollback**. Karada routes traffic back to the prior stable container with zero downtime.

### Custom Domains & Managed TLS

By default, every project receives a secure `https://<project-slug>.karada.ai` endpoint. You can also bind custom enterprise domains via standard DNS CNAME records. Karada automatically issues and renews Let's Encrypt TLS certificates at zero extra cost.
